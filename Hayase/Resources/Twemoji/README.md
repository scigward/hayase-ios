The interface renders extension language flags and peer countries with its
Twemoji Mozilla font. This iOS atlas contains the corresponding flag and globe
artwork from Mozilla's `twemoji-colr` v0.7.0 source archive (`twe-svg.zip`,
Twemoji SVG v14.0.1). The artwork was resized and packed into `flags.png`;
`flags.json` maps country codes to atlas cells. No other app emoji are replaced.
